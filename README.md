# WB 样本配平工具

一个纯前端的 Western blot 样本配平计算器。数据只在当前浏览器中处理，并通过 `localStorage` 保存，不会上传到服务器。

## 主要功能

四种配平模式，各模式的样本数据分别保存，切换互不影响。

**变性后重新配平（等浓度稀释）**

适用于已经完成变性的样本。以最低浓度样本为目标浓度，通过加入 1× Loading 将各样本稀释至同一浓度：

```text
目标浓度 = min(所有样本浓度)
总蛋白量 = 当前浓度 × 样本体积
最终体积 = 总蛋白量 ÷ 目标浓度
需加 1× Loading 体积 = 最终体积 − 样本体积
```

默认所有样本体积相同，通过全局「样本当前体积」设置。也可勾选「各样本体积不同」逐样本填写。

最低浓度样本无需加入 1× Loading。

**上样配平**

按每孔目标蛋白量和各样本浓度计算取样体积，用 1× Loading 补足到统一上样体积：

```text
样本体积 = 每孔目标蛋白量 ÷ 蛋白浓度
1× Loading 体积 = 统一上样体积 − 样本体积
```

以上为无损耗、无预稀释时的基础公式；启用损耗补偿后原液消耗量同比放大，预稀释后显示的是稀释液移液体积。守恒校验应使用「原液消耗量 × 原液浓度 × (1−损耗率) = 目标蛋白量」，或用「稀释液移液体积 ×（原液浓度 ÷ 稀释倍数）×（1−损耗率）」近似校验目标蛋白量。预稀释建议体积保留到 0.001 µL，界面显示另有小数格式化，不按移液器步进量化。

理论取样体积小于 0.5 µL 时会给出预稀释建议；可设置预计损耗率（%），使用严格补偿公式 1/(1−x%) 放大总体积和样品量，保证损耗后剩余量仍满足目标。

**ImageJ 配平**

适用于完成一次 WB 后，使用 ImageJ 对内参条带进行相对定量的情况。ImageJ 内参值即视为相对浓度，以最低 ImageJ 值为参考，按比值修正取样量：

```text
损耗补偿系数 = 1 ÷ (1 − 预计损耗率/100)
配制总体积 = 目标统一上样体积 × 损耗补偿系数
修正样本体积 = 配制总体积 × (最低 ImageJ ÷ 样本 ImageJ)
1× Loading 体积 = 配制总体积 − 修正样本体积
```

1× Loading 为 0 µL 表示无需添加，不触发小体积警告；参考值并列时可以有多个零值。零附近不超过 1e-9 µL 的浮点余量按零处理；真正大于零且小于 0.5 µL 的添加量仍警告，小于 0.005 µL 时显示并复制三位有效数字，避免舍入成零。

不启用预稀释时，最低 ImageJ 样本占满损耗补偿后的配制总体积，其余按比例缩减。配制量可能大于目标上样体积：例如目标 20 µL、损耗 10%，最低参考样本需配制约 22.22 µL。理论取样量小于 0.5 µL 时，结果会显示预稀释后的移液体积。如各样本上一轮取样体积不同，需全部填写「上轮取样体积」，以 ImageJ ÷ 上轮体积作为相对浓度重新确定参考值；所有数值有效样本的上轮体积须全部留空或全部填写正的有限数字。任何非空非法值（含 0、负数、非数字或无穷大）都会阻止该次配平及结果复制。

**未变性样品配平**

适用于未变性的蛋白样品，同时计算三部分体积（支持 2× / 4× / 5× / 6× Loading Buffer）：

```text
样品体积 = 目标蛋白量 ÷ 蛋白浓度
Loading Buffer 体积 = 终体积 ÷ Buffer 倍数
补液体积 = 终体积 − 样品体积 − Loading Buffer 体积
```

未变性模式同样先按预计损耗率同比放大样品量和总体积，再应用预稀释建议；Loading Buffer 取补偿后总体积的 1/倍数，补液为余量。蛋白量守恒仍按上面的原液消耗量公式校验。

**数据导入与导出**

- **粘贴数据**：从 Excel 复制数据（制表符分隔）后直接粘贴到页面。注意列含义随模式不同：ImageJ 配平模式下第二列是 ImageJ 内参值，其余模式下第二列是蛋白浓度。第三列为可用体积；变性后重新配平的第四列为逐样本当前体积（仅勾选「各样本体积不同」时参与计算），ImageJ 的第四列为上轮取样体积。
- **复制结果**：将结果表以制表符分隔文本复制到剪贴板，可直接粘贴回 Excel。

## 界面风格

采用暖米白、浅灰与赤陶色，衬线标题与系统无衬线正文保持统一层级，图表与状态提示保留必要的颜色区别。

页眉内容区居中，品牌与标题靠左，操作靠右；页眉位于文档顶部，随页面正常滚走，窄屏允许换行。页眉背景与分隔线铺满页面宽度。

正常样本上样量和 Loading 用量采用浅米灰底、深色加粗数字；红色与黄色用于实际异常或警告。非法输入会阻止计算，四种工作流可保存和恢复。

## 数据与隐私

应用是纯静态网页，所有计算在浏览器本地完成，数据通过 `localStorage` 保存，不上传任何服务器。每个模式的样本数据分开保存，切换模式互不影响。

## 本地运行

对外版本以 GitHub Release 为准；项目没有独立的应用版本常量，发布不更改本地存储格式。

没有构建步骤，任选其一本地预览：

- 直接双击打开 `index.html`；
- `python -m http.server 8000` 后访问 `http://localhost:8000`；
- `npx wrangler pages dev .`（模拟 Cloudflare Pages 环境）。

## 部署

部署到 Cloudflare Pages：连接 GitHub 仓库自动部署（Framework preset 选 `None`，build command 留空，输出目录 `.`），或命令行：

```bash
npx wrangler pages deploy . --project-name wb-balancer
```

页面按内容标识引用样式与计算脚本；发布时同步更新资源标识，避免新页面混用旧资源缓存。

## 责任边界

本工具只负责体积计算。正式实验前，请结合试剂说明书和实验室 SOP，复核移液器量程、最小可靠移液体积、样本损耗以及修正后的总蛋白量是否符合实验设计。
